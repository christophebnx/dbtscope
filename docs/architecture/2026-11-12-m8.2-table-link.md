## Context

**Request.** A link such as `erd.html#table=model.acme_retail.fct_orders` opens the page on that table; a **Copy link** action in the page gives that link. It must work for a page opened from a file (`file://`) and for a hosted page, identify the table by its dbt `unique_id` (invariant 11), and add no stored format (invariant 9).

**Current code.**

- `boot.js` starts the tab of `PAGE.view` (`showTab`), builds the stateful services (`LAYOUT`, `EXPORT`, `openFlow`, `closeFlow`) and passes them to the views. Nothing reads `location`.
- `universe.js` enters the trajectory mode with `enterTrajectory(i)` (reveal of filtered-out tables, D-018), leaves it with `leaveTrajectory`, frames it with `fit()` (the trajectory while the mode is on). The trajectory bar `#u-trajbar` holds **Flow** and **Leave**. `trajectoryState()` is the test hook.
- The browser tests open pages with `page.goto(html.as_uri())` (`tests/browser/conftest.open_page`).

## Chosen design

### 1. The link form (D-059)

- **Form:** `<page URL without fragment>#table=<encodeURIComponent(unique_id)>`. `encodeURIComponent` leaves `.`, `_` and `-` as they are, so a dbt id stays readable: `erd.html#table=model.acme_retail.fct_orders`, `#table=source.acme_retail.erp.orders`.
- **Reading:** the fragment is parsed with `new URLSearchParams(location.hash.slice(1))`; only `table` is read, other keys are ignored (room for later keys without a new form). `URLSearchParams` never throws: a malformed `%` sequence decodes to U+FFFD and simply matches no table.
- **Matching:** the exact `unique_id` among `PAGE.universe.nodes` only. No name matching: a source and a model may share a name, and a name link would change meaning when a table is added.
- **Not stored:** the fragment is never written to `dbt-erd-layout.json`, to `LAYOUT` or to localStorage, and Python never sees it. It is a public contract all the same, since links are pasted into tickets and wikis: D-059 freezes the key `table` and its value (the `unique_id`); a change needs a superseding decision that keeps reading the old form (the D-013 rule, applied to links).

### 2. What a link opens

- **The Universe tab, in trajectory mode on the table, framed.** Whatever `PAGE.view` says, boot shows the Universe tab and calls the new handle method `views.universe.select(id)`: `enterTrajectory(i)` (with the session's direction and depth, by default both / all levels), then `fit(false)`, which frames the trajectory. The reader sees the table among its domain, with where its data comes from and where it goes, and the **Flow** button one click away.
- **Filters:** D-018 holds: a table hidden by the default filters (`hiddenKinds`, or a domain unticked) is brought back with its trajectory and counted in the bar.
- **A table with no lineage:** the mode shows its empty text ("No upstream or downstream table") and Fit frames the table alone (the existing `fit` at most scale 2).
- **Not found** (excluded by `universe.select` / `exclude`, renamed, or a typo): the page opens as without a link (the tab of `PAGE.view`), and a visible, polite message says so **[UI]**: proposal, a dismissible line at the top of the universe stage, "No table <id> in this map", the id set with `textContent` (untrusted). No `alert()`: a link from an older page must not block the reader. The fragment is left as it is.

### 3. The address follows the trajectory

- **Entering or moving the trajectory** (click on a table, **Trajectory** button, a link) writes `#table=<id>` into the address bar; **leaving** it (Leave, `Esc`, background click) removes the fragment. So the address bar is always a link to what is shown, and the browser's own "copy URL" also works.
- **No history entries:** `history.replaceState(null, '', url)`. Back leaves the page, as today, instead of replaying every click. If `replaceState` throws (a browser that refuses it on `file://`), the fallback is `location.replace('#' + fragment)` (same document, no reload, no history entry); a failure of both is ignored: the page keeps working, only the address does not follow.
- **A changed fragment** (the user edits the address, or pastes another link into the same tab): a `hashchange` listener in boot calls `views.universe.select(id)` again; an empty or unknown fragment leaves the trajectory as it is (no surprise exit). Writing the fragment from the page itself never loops: `replaceState` fires no `hashchange`, and the fallback's `hashchange` names the table already shown (no-op).
- **The flow view** does not change the address: it is an overlay that saves nothing (D-036), and its recentre never moves the universe trajectory. Closing the flow returns to the trajectory, whose link is still in the address bar.
- **The detail tab** does not change the address either; switching tabs keeps the fragment.

### 4. Copy link **[UI]**

- A **Copy link** button in the trajectory bar, next to **Flow** (proposal: `… [Copy link] [Flow] [Leave]`), title "Copy a link that opens this page on this table". It copies `LINK.url(id)` of the trajectory's start.
- **Copying:** `navigator.clipboard.writeText` (available on `file://` and HTTPS in current browsers, a secure context). On success, the trajectory live region `#u-tj-live` says "Link copied" and the button keeps focus. If the API is missing or rejects (plain HTTP, permissions), a small popover shows the link in a read-only text field, selected and focused, with "Copy this link" so the user presses Ctrl+C / Cmd+C; `Esc` or a click outside closes it. No `document.execCommand('copy')` (deprecated).
- **What the link holds on `file://`:** the local path of the file. It opens for whoever has the same file at the same path (a shared drive); otherwise a hosted page is needed. The user guide says so; the page does not try to detect it.

### 7. Errors

- Unknown or malformed fragment: the not-found line, no exception, no trajectory.
- Hostile fragment (`#table=%3Cimg%20src%3Dx%20onerror%3D…%3E`): matched against ids only, shown with `textContent`: nothing injected.
- `replaceState` and `location.replace` both refused: ignored (§ 3).
- Clipboard refused: the popover (§ 4).
- Nothing written to disk or storage.

## Rejected options

- **Opening the Detail tab on the table:** the detail payload holds only the detail selection (many sources and staging tables are not in it), so a link would fail for them.
- **Opening the flow view:** a Graphviz render on load, and a reader without the map's context; the flow is one click away from the trajectory.
- **Search mark only, no trajectory:** the address would then mean two different things depending on how the table was reached; the trajectory is what a click already shows.
- **Table names in the link:** ambiguous (a source and a model with one name) and unstable as projects grow.
- **`pushState` (a history entry per click):** Back would replay clicks instead of leaving the page.
- **The flow or the detail writing the address:** both are views that save nothing; the link stays "this table in the map".
- **Direction and depth in the link** (`&dir=up&depth=2`): more form to freeze for little gain; the defaults show everything. Unknown keys are ignored, so a later decision can add them.
- **A query string (`?table=`):** on `file://` some browsers drop or refuse the query, and a hosted server could treat it as a different resource; the fragment never leaves the browser.
- **`document.execCommand('copy')`:** deprecated; the read-only field works everywhere.

## Impacts

### Decision D-059 (proposed; appended to `docs/decisions.md` by the documentation step, after D-058)

> **D-059 — A page link opens the universe on one table: `#table=<unique_id>`; the address follows the trajectory.**
> Asked by the user on 2026-11-12 (M8.2, design note `docs/architecture/2026-11-12-m8.2-table-link.md`). A page URL with the fragment `#table=<unique_id>` (the dbt `unique_id`, written with `encodeURIComponent`, read with `URLSearchParams`; other keys ignored) opens the Universe tab in trajectory mode on that table, with the session's direction and depth, framed by Fit; D-018 holds (filtered-out tables of the trajectory are brought back). An id not in the universe payload leaves the page as without a link and shows a dismissible message. Entering or moving the trajectory writes the fragment, leaving it removes the fragment, with `history.replaceState` (no history entry; fallback `location.replace`); a changed fragment moves the trajectory. The flow view and the detail tab never change it. **Copy link** in the trajectory bar copies the link with the Clipboard API, else shows it selected in a read-only field. The fragment is never stored (no layout, no localStorage, D-013) and holds only an id (invariant 8), but links are shared, so the key `table` and its value are frozen like the project files of D-013: a change needs a superseding decision that still reads this form. No payload change. Rejected: opening the detail or the flow, a name instead of the id, `pushState`, direction and depth in the link, a query string, `execCommand('copy')`.

## Risks

1. **`replaceState` on `file://`.** Chromium and Firefox accept a same-document fragment change; the fallback covers a browser that refuses it.
2. **Clipboard API on `file://`.** Chromium treats `file://` as a secure context; the popover covers the others.
3. **A table at the edge of a large constellation:** `fit` frames the whole trajectory, which may be large; the start ring marks it (M1).

## UI design (ui-designer, 2026-11-12)

Resolves every **[UI]** point of §§ 2, 4 and 6. No `NEEDS USER APPROVAL`: the behaviour was approved on 2026-11-12; what follows is wording, placement and states.

### Task and decision

Someone pastes a link from a ticket or wiki and must see, at once, which table it names and what surrounds it. Someone looking at a table wants to send "this one" to a colleague in one action. Decision served: "is this the table I was told about, and where does its data come from / go?" Fewest steps: the link opens already framed; Copy link is one click in the bar already on screen.

### Layout

Copy link sits in the trajectory bar between the legend and **Flow**: the actions stay together at the end, **Leave** last (unchanged place).

### Components

- **`#u-tj-link`**: native `button`, same class as **Flow** (no accent fill: the accent stays for the state in progress). Title `copyLinkTitle`. Enabled whenever the mode is on.
- **Feedback, sighted and not:** on success the button text becomes `copied` ("Link copied") for 2 s, then returns to `copyLink`; the live region `#u-tj-live` says the same once. The text swap, not a toast, so the message appears where the eye already is. The button keeps focus and its width may change by a few characters (the bar wraps anyway). A second click during the 2 s copies again.
- **Fallback popover `#u-tj-copy`:** a native `popover="auto"` element (light dismiss: `Esc` and click outside close it, and focus returns to the invoking button, both given by the browser; no custom code, no dialog). Content: a `label` ("Copy this link: Ctrl+C or Cmd+C") tied by `for` to a read-only `input type="text"` holding the link, selected and focused on open. The input is read-only, not disabled, so it can be selected and read by screen readers. A browser without the `popover` attribute: the element is shown with `hidden` toggled and `Esc` / a click outside handled by the existing bar listener (one `keydown` branch, the same as the breakdown's).
- **Not-found line `#u-notfound`:** a `div role="status"` at the top of the stage (polite, announced on load), surface background, 1 px `--border`, text `--fg`, a **Close** button. The id sits in a `span` set with `textContent`, `overflow-wrap:anywhere` so a long id wraps at 360 px. It disappears on **Close**, on entering any trajectory, or on a later valid link. It does not time out (a link from an old page must not vanish before it is read). **Close** returns focus to the first control of the universe toolbar if it had focus.
- Reuses the trajectory bar's button style, live region and `Esc` rules; no new helper.

### States

| State | What is shown |
|---|---|
| Link to a table | Universe tab, trajectory on it, framed; bar with counts; address holds the fragment |
| Table with no lineage | the existing "No upstream or downstream table"; Copy link enabled, Flow disabled |
| Copying | instant; no spinner |
| Copied | button reads "Link copied" 2 s; live region |
| Clipboard refused | popover with the selected link |
| Table unknown, non-empty `table` | not-found line; page as without a link |
| Empty or foreign fragment (`#table=`, `#foo=1`) | nothing shown, page as without a link |
| Filters hide the table | brought back and counted (D-018), nothing new |

### Keyboard and focus

Tab order in the bar: Direction, Depth, counts, Copy link, Flow, Leave. Enter or Space on Copy link copies. In the popover: focus starts in the field (text selected); `Esc` closes it and focus returns to Copy link. On load from a link, focus is not moved (the page does not steal it); the not-found line is announced by its live role, not focused. Coarse pointer: Copy link, Close and the popover field are 44 px high; the popover field does not scroll the page at 360 px.
